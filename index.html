    Mise en route

    Deux façons de travailler : dans le navigateur avec GitHub Codespaces, sans rien installer, ou sur votre machine avec votre IDE.

    En ligne, sans rien installer Conseillé

    Codespaces ouvre tout le dépôt dans VS Code, dans le navigateur, avec Java 21 et les bibliothèques du cours déjà installées. Il faut un compte GitHub : le compte gratuit donne environ 60 heures par mois, et Codespaces est gratuit pour les étudiants inscrits à GitHub Education.

    1. OuvrirOuvrir dans Codespaces ↗. Le premier démarrage prend quelques minutes, les suivants reprennent votre espace là où vous l'aviez laissé.
    2. LancerCopier la commande lancer … d'une carte et la coller dans le terminal. Ou ouvrir le fichier et faire Ctrl+Maj+B.
    3. Voir les fenêtresPour Swing, JavaFX ou Ludii : onglet Ports, ligne 6080, icône globe, puis Connect (mot de passe vscode).

    Sur votre machine

    Chaque dossier est un petit projet indépendant, à ouvrir dans un IDE avec un JDK 17 ou plus récent.

    1. Récupérer le codeCloner le dépôt ↗, ou sur GitHub : Code → Download ZIP.
    2. Ouvrir le projetOuvrir le dossier dans IntelliJ IDEA, Eclipse ou VS Code. Marquer src comme dossier source si besoin.
    3. LancerAjouter la bibliothèque éventuelle (tableau ci-dessous), puis exécuter la classe indiquée sur la carte.
